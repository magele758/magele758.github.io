Transparent MV3 Permission Scope

Permission Exact Local-First Justification
activeTab 仅在用户主动点击扩展图标开启当前视频同传时，获取当前活动标签页的视频元信息与播放时间轴。
storage 在浏览器本地安全存储用户的模型配置、BYOK API 密钥、配音偏好与 Ed25519 离线授权凭证，不同步至第三方广告服务器。
offscreen 在 Manifest V3 Service Worker 架构下创建隔离 Offscreen Document，用于低延迟音频重采样、混音与中文语音合成播放。
tabCapture 仅在用户显式点击开始同传后捕获当前视频标签页音频流以执行实时语音识别与原声闪避（Ducking），不后台静默录制。
